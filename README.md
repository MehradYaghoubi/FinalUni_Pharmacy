# Pharmacy E-commerce Backend

A university project focused on the backend of a pharmacy e-commerce application, built with .NET 5.

## Project focus

The repository contains a layered backend for pharmacy catalog and commerce workflows. Source code is organized under the Pharmacy directory.

## Requirements and setup

- .NET 5 SDK
- A compatible database server and the connection settings expected by the application

.NET 5 is out of support. Treat this as a legacy educational project. Upgrade the runtime and review authentication, authorization, and dependencies before deploying it publicly.

```bash
git clone https://github.com/MehradYaghoubi/FinalUni_Pharmacy.git
cd FinalUni_Pharmacy
```

Open the solution in Visual Studio or build it with the .NET CLI. Configure required database connection strings locally; do not commit credentials or production connection strings.

This repository documents an academic backend project and is not a maintained pharmacy service.
